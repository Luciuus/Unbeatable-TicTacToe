# Tic Tac Toe AI

Modern Tic Tac Toe with:
- Multiple AI difficulties
- Unbeatable Minimax AI
- Responsive UI
- Next.js + TypeScript + Tailwind CSS

---

# Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Unbeatable-TicTacToe.git
```

Enter the project:

```bash
cd Unbeatable-TicTacToe
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

---

# Build

```bash
npm run build
```
